0 · HIỆN TẠI

Baseline để đối chiếu

Copy 1:1 code cũ. Bấm D để thấy vùng chết co giãn theo chiều rộng cửa sổ.

A · TRANG BÀI VIẾT

Reading rail

256px kia trở thành rail sticky: progress ring, TOC scrollspy, tag, đọc tiếp. rail chỉ hiện ≥1024px.

Đổi lại: phải trích h2/h3 từ HTML Quill để sinh TOC.

B · MỌI TRANG

Centered single column

Bỏ lg:mr-64, thêm mx-auto, max-w-2xl. Kiểu Overreacted / Julia Evans.

Ít code nhất (~2 dòng CSS), không thêm tính năng, không thêm chi phí build.

C · TRANG LIST

Ambient rail

Rail hẹp 160px chỉ chứa chrome: scroll indicator, số bài, archive theo năm, RSS, back-to-top.

An toàn nhất về mặt content — nhưng với 47 bài thì chủ yếu vẫn là trang trí.

D · TRANG LIST

Two-column index

Vùng chết trở thành cột thứ hai của lưới bài viết, dùng grid thật thay vì margin dự phòng. Có 1 bài featured chiếm 2 cột. Cần thumbImage đẹp cho bài nào có, bài không có vẫn ổn (khối text thuần).
